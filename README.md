One haiku about debugging, in strict 5-7-5, written by `main.ts` to `/output/entry.txt`:

> Breakpoint waits, silent
> cursor blinks at 3 a.m.
> and the bug was me

The picture at its centre is concrete — a breakpoint holding, a cursor blinking at 3 a.m. — and the last line reframes the whole night: the bug was never in the code, it was the person staring at it.

## Run

```sh
node main.ts
```

The program validates the haiku first (1–200 characters, not only whitespace, exactly 3 lines, syllable counts 5-7-5), writes it to `/output/entry.txt`, then reads the file back and verifies it.
